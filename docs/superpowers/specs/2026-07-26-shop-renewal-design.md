## 6.5 「公式感」の要素（参考ストア調査で追加。退屈な構造の一部として必須実装）

参考: ちいかわマーケット / カナヘイの小動物ゆるっとストア / パペットスンスン / サンエックス公式ストア 等。キャラ公式ECの「公式感」は以下の標準要素で作られる。**全部こすくまボイスで書くが、情報としては正確に**（声が情報を犠牲にしない）:

1. **「公式」の明示**: title・ヘッダーに「公式グッズショップ」表記（例: `こすくまくんのおみせ｜公式グッズショップ`）
2. **価格は「税込」表記**: 全ての価格表示に `（税込）` を付記（日本EC標準。ちいかわマーケットも全商品税込表記）
3. **お知らせ（INFORMATION）セクション**: トップに日付付きお知らせリスト（新着・休業・発送・問い合わせ窓口）。静的HTMLに手書きで手堅く。日付＋内容の退屈なリスト構造
4. **お知らせバー**: 冒頭の帯（現行の送料無料アナウンスを格上げ）で重要告知を1件
5. **サポート対応の明記**: 「メールは24時間受付・返信は営業日」をガイド/FAQに明記（カナヘイ方式）
6. **公式SNSリンク**: フッターに X `@Kosu_dot_kuma` へのリンク（公式であることの相互認証）
7. **運営会社情報**: 株式会社こす.くま・所在地・問い合わせ先（現行フッター温存）
8. **ガイドの充実**: 送料・発送日数・返品・支払い方法を標準EC通り網羅（既に計画済みのguideセクションで実現）

やらないこと（商品数3点の現状では過剰）: 会員ログイン、お気に入り、ランキング、最近チェックした商品、カテゴリナビ、バナーカルーセル

## 4. 技術基盤（現行維持）

- 静的HTML + vanilla JS + Shopify Storefront Cart API。フレームワーク・ビルド工程なし
- 現行READMEの鉄則を継承:
  1. カートをフロントで自前計算しない（数量変更・削除も必ずShopify API経由）
  2. 価格・通貨をフロントで捏造しない（常にShopifyのMoney型から。JPYオンリー）
  3. 商品の紐付けはhandleのみ（`js/config.js`）
  4. 演出はz-index階層表（`css/tokens.css`）より上に出さない。購入UIは聖域
  5. ブレークポイントは 640/900 固定（`js/fx/motion.js` と css で同一情報源）
- 温存・流用: `js/storefront.js`（GraphQL薄層）、`js/cart.js`（カートの真実）、`js/config.js`（handle一覧）
- カートは現行の**ドロワー方式を維持**（headless構成の標準パターン。過去の過剰請求バグの教訓がcart.jsに集約済み）
- チェックアウトは現行同様 Shopify の checkout URL へ遷移（Shopify標準画面＝最も退屈で信用できる）

## 6. ビジュアル設計 — ドット絵はアクセント、キャラクターが主役

**構図: 「こすくまくんの暮らす場所に、店が建っている」**

- **こすくまくんはドット絵にしない。** 公式のクリーンなスタイル（`front.png`・コマアニメ・正典準拠の生成ポーズ）のまま主役として据える
- **ドット絵はアクセント。** 完全なドット絵世界にはせず、ヘッダー/ヒーロー背景/セクション区切り/フッターの帯にkigyo-ip系ドット絵（`base-map-day.png` 等）を使う。商品グリッド・フォーム・価格表示は退屈なほど普通の白カードUI
- **背景は時間帯で変化**: 昼/夕/夜の複数パターンを生成パイプラインで作り、訪問時刻に応じて色と雰囲気が変わる。**夜は暗くして焚き火**（焚き火のそばにこすくまくん、が夜の顔）
- ページごとのこすくまくん:
  - トップ: ヒーローで店番（or 店の前で昼寝）。ジャイロ金平糖は彼の周りを舞う演出として再統合
  - 商品詳細: 商品の横に立つ案内係。「これ、いいよ」的な一言を添える
  - カート（ドロワー）: レジ係として佇む
  - 404: 道に迷ったこすくまくん
  - フッター: 時間帯で姿勢が変わる（夕方は焚き火、夜は寝ている）
- **公式素材ルール遵守**: 静止画は公式アセットまたは正典準拠の生成物のみ。同一アニメは1ページ1個まで。等身比率を守る（サイズ差の笑いは禁止）
- 世界観の演出がページ速度・購入導線を犠牲にしない（芸は軽く。画像はWebP/srcset、遅延ロード。背景の時間帯切替はプリロード済みの軽量CSS/画像差し替えで、レイアウトシフトを起こさない）

## 9. アセット生成パイプライン（おしゃべり漫画ロジック移植）

ショップ用ローカルツール `tools/gen-kosukuma.mjs` として実装。**サイト実行時には生成しない**（速度予算遵守。事前生成して `assets/gen/` に焼く）。

生成物は2系統:

**A. こすくまポーズ（透過PNG・公式スタイル。ドット絵にしない）**

移植する核（出典: `D:/ダウンロード/motomokonai-kosukuma/lib/orchestrator/` + `lib/refs.ts` + `lib/config.ts`）:

- **正典スペック**: 白いまん丸マシュマロ体型・点目2つ＋小さな横長だえんの鼻（ω・波線・w型は全て禁止）・**口は絶対に描かない**・しっぽは丸いの1個・見えている側の腰〜お尻下部に平らな黒いほくろ1つ（足・脚・しっぽ・顔・胸は禁止）。`MOUTH_BAN` 方式でプロンプト**先頭＋末尾に二重配置**
- **参照画像**:
  - 同一性: 正面スタンプ系（motomokonai-kosukuma `public/refs/01-front.png` 等を借用）
  - 画風: 公式のクリーンなスタイル（`front.png` 等）。**ドット絵参照は混ぜない**
- **生成**: gpt-image-2（images.edit・参照画像方式）で best-of-2 並列生成
- **SELECT**: ビジョンモデルが2枚を比較選抜。破綻基準（別キャラ化・鼻の形誤り・口の存在・ほくろ位置誤り・画風不一致）を移植。両方破綻なら軽い方を採用＋ログ記録
- 生成対象は「既存公式素材に無いポーズが必要な時だけ」（例: 店番・商品案内・レジ係・道に迷う・焚き火のそば）。透過PNG出力
- 既存素材で足りる場面では生成しない（再生成の乱造を防ぐ）

**B. 時間帯背景（昼/夕/夜・夜は焚き火）**

- kigyo-ipの `base-map-day.png` 系ドット絵を画風参照に、夕暮れ版・夜版（暗転＋焚き火）を生成
- こすくまくんは背景に焼き込まない（別レイヤーの透過PNGとして合成。時間帯切替・ポーズ差し替えを可能にするため）
- パターン数は必要最小限（ヒーロー用の昼/夕/夜 + 必要なセクション帯）。WebP化＋srcsetで軽量化
