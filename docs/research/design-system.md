## 1. デザイン原則 — こすくま独自トーンの言語化

1. **紙と墨の店、蜜が一滴。** UI層は「生成りの紙 × 墨の太線 × はちみつ色のアクション」だけで構成する。にぎやかさはドット絵の世界（背景fx層）と金平糖（hero 3D）が担当し、UI層は静かに商品を見せる。この分業が「公式の節度」。
2. **世界は窓から見せる。** ピクセル背景は聖域として維持するが、コンテンツの背後ではなく**セクション間の全幅の「窓」**として見せる。文字とピクセル世界は同じレイヤーに同居させない。
3. **線はキャラと同じ墨。** こすくまくんの黒太アウトラインが唯一のブランド線。カード・ボタン・バッジの輪郭はすべて同じ墨色 2px。ここが「キャラと売り場が同じ筆で描かれている」感＝公式らしさの核。
4. **色は減らすほど公式になる。** 実測でちいかわマーケットのUI有彩色は実質2系統。本システムはUI有彩色を **honey / wood / moss の3系統**に制限する。
5. **かわいさは形でなく振る舞いで。** 丸ゴシック・大きめ角丸・押し込みボタンの3点で十分かわいい。装飾を足すのではなく、規律を守ることでかわいさが上品に見える。
6. **全年齢の店は煽らない。** 偽の希少性・カウントダウン・点滅は禁止。正直な情報（税込・送料・発送日数・売り切れ事実）を静かに置く。

## 2. 聖域（本システムが絶対に触れないもの）

- `js/config.js` / `js/storefront.js` / `js/cart.js`（金額自前計算禁止を含む）

- 背景ドット絵 `assets/pixel`（使い方は §7 で規定するが、素材と存在は不変）

### 3-1. 導出と統制

## 4. タイポグラフィ

書体は **M PLUS Rounded 1c 維持**（フォールバック: Zen Maru Gothic → Hiragino Maru Gothic ProN → sans-serif）。数字も同族で通貨・価格に使用。

### 4-1. スケール（7段で固定。これ以外のfont-size新設禁止）

| トークン | サイズ | weight | 行間 | 字間 | 用途 |
|---|---|---|---|---|---|
| `--fs-hero` | `clamp(1.75rem, 1.3rem + 1.8vw, 2.375rem)` | 800 | 1.3 | 0.02em | ヒーローh1（1行維持） |
| `--fs-h2` | `clamp(1.375rem, 1.1rem + 1.2vw, 1.75rem)` | 700 | 1.35 | 0.02em | セクション見出し |
| `--fs-h3` | `1.1875rem` | 700 | 1.5 | 0.02em | カード見出し・FAQ質問 |
| `--fs-body` | `1rem` | 400（商品名は500） | 1.8（長文1.9） | 0.01em | 本文・商品名 |
| `--fs-price` | `1.25rem` | 700 | 1.2 | 0 | 価格（**SPでも縮小しない** — 実測型） |
| `--fs-small` | `0.875rem` | 400 | 1.6 | 0.01em | 補足・(税込)・日付 |
| `--fs-label` | `0.75rem` | 700 | 1.2 | 英字0.14em / 和字0.06em | バッジ・英字セクションラベル |

- **weightは 400 / 500 / 700 / 800 の4つのみ**。300以下は可読性、900は圧が出るため禁止。
- セクション見出しは「小さい日本語ラベル（--fs-small, ink-sub）＋大きい英字ラベル（--fs-h2, ink, 字間0.14em）」の**2段中央揃え**で全セクション統一（構造の型。ITEMS / NEWS / GUIDE / FAQ…）。
- 日本語組版必須3点: ルートに `lang="ja"`、見出しは `text-wrap: balance` + `word-break: auto-phrase`、本文は `text-wrap: pretty`。`font-feature-settings: "palt"` は**見出しのみ**（本文はベタ組み）。
- 価格表記: `¥780`（fs-price / 700 / ink）＋ `（税込）`（fs-small / 400 / ink-sub）。カード内では**右揃え**。
- 文言は聖域。表示上の改行調整は `<wbr>`・分節spanのみで行う。

## 5. スペーシングとグリッド

### 5-1. スケール（4px基数、9段）

```css
--space-1: 4px;  --space-2: 8px;  --space-3: 12px;  --space-4: 16px;
--space-5: 24px; --space-6: 32px; --space-7: 48px;  --space-8: 64px; --space-9: 96px;
```

任意値の余白（28px, 44px, 72px等）は全廃し、この9段に吸着させる。既存 `--space-*` の参照は近傍段へ丸める（28→24 or 32、44→48、72→64 or 96）。

### 5-2. グリッド規律（実測型の移植 — 構造のみ）

| 項目 | PC | SP(≤640) | 備考 |

| コンテナ | `--content-max: 1400px`・gutter 50px | gutter 15px | 1920でも全幅に伸ばさず中央固定 |
| 商品グリッド | 4列・gap 12×12（SKU3点の現状は3列・gap 12も可。**列は等幅厳守**） | 2列・gap 12×32（縦広め） | `--space-3` 基準 |
| カード内pad | 16px | 8px | |
| セクション縦リズム | 上pad 96 → 2段見出し → 48 → コンテンツ → 下pad 96 | 64 → 見出し → 32 → コンテンツ → 64 | **全セクション同一リズム**（G8対策） |

## 6. コンポーネント規格（線・角・影・ボタン・アイコン）

### 6-1. 統一値

| 属性 | 値 | 規則 |
|---|---|---|
| 角丸 | `--radius-s: 8px`（入力・バッジ・画像） / `--radius-m: 14px`（カード・ボタン） / `--radius-l: 22px`（ヒーローパネル・ドロワー） / `999px`（ピル） | この4値以外禁止 |
| ブランド線 | `--line-brand: 2px solid var(--ink)` | 対話要素（ボタン・バッジ・ピル・カード枠）に使う唯一の枠線。**キャラの黒太アウトラインと同じ墨**（G4対策） |
| 区切り線 | `--line-hair: 1px solid rgba(43,33,22,0.12)` | リスト区切り・表罫のみ |
| 影 | `--shadow-card` / `--shadow-pop` の2種のみ | **色付き影禁止**（G5対策）。hover浮きは translateY(-2px)+shadow-pop まで |
| 押し込み | `--press-shadow: 0 3px 0 var(--ink)` → active時 `0 1px 0` + translateY(2px) | 「押せる」表現はこのハードオフセット1種。ぷにっと感はこれで出す |

### 6-2. ボタン（3種のみ。第4のボタン様式を作らない）

| 種 | 仕様 | 用途 |
|---|---|---|
| Primary | `--honey` 塗り + `--line-brand` + `--ink` 文字(700) + `--press-shadow`、radius-m | **「カートに入れる」「レジへ進む」専用**。1画面に同格primaryを並置しない |
| Secondary | `--surface` 塗り + `--line-brand` + `--ink` 文字、radius-m | 「くわしく」「買い物を続ける」等 |
| Text link | `--honey-deep` + 下線必須 | 本文内導線・「再入荷のお知らせ」 |

- **木目・看板・ビットマップテクスチャのボタンは全廃**（G2対策）。ヒーローの「おみせを見る」・商品詳細CTAもこの3種に統一。
- 無効状態は disabled 3トークン + `cursor: not-allowed`。文言はそのまま（「うりきれ」等の声は聖域）。

### 6-3. バッジ・状態表示（G7対策）

- 在庫状態バッジはカード**左上の1箇所のみ**（ピル型・line-brand・fs-label）。吹き出し型の重複表示は廃止し、こすくまくんの一言（「うりきれちゃった」等の聖域文言）はカード**内部の説明文位置**に移す（文言不変・位置の整理のみ）。
- 意味論: あるよ=`moss-soft`地+`moss`文字 / うりきれ=`disabled-bg`地+`disabled-text`文字 / 近日=`cream`地+`ink`文字。**色だけで意味を伝えない**（必ず文字併記 — 全年齢原則）。

### 6-4. アイコン（G6対策）

- 絵文字・システムフォント記号・素の1文字（"X"）をアイコンとして使用禁止。**2px墨線・角丸端点の自作ラインアイコン1セット**（カート・メニュー・矢印・X(SNS)・検索・閉じる）で統一。サイズ24px（タップ領域44px）。
- ヘッダー機能ボタンはアイコン+小ラベル文字（fs-label）の組で揃える。

## 7. レイヤー分離と装飾の節度

### 7-1. ピクセル世界の見せ方（G1対策・最重要）

- z構造は聖域どおり fx(1) < content(10)。その上で: **文字・商品写真は必ずサーフェス（--paper / --surface / --cream系の不透明面）上に置く。ピクセル背景の上に直接テキストを置くことを全面禁止**（例外なし。見出しも同様）。
- ピクセル背景は「セクション間の全幅の窓（帯）」として露出させる: `コンテンツゾーン(paper不透明) → 世界の窓(全幅・高さ160-280px・文字なし) → コンテンツゾーン` のサンドイッチ。ゾーン切替が背景色切替を兼ね、境界線なしで区分けできる（実測型§7の移植）。
- コンテンツゾーンの `--page-veil` は不透明化（`rgba(253,249,236,1)` 相当）。半透明ヴェール越しの本文は禁止。商品詳細の `--page-veil-detail: 0.88` は 1.0 へ。
- ヒーローのパネルは `--surface` or `--paper` の不透明カード（radius-l・line-brand・shadow-card）。背景が透ける演出はパネル外のみ。

### 7-2. 禁止表現リスト（同人感の源。レビューで一発差し戻し）

1. 木目・布・紙テクスチャのビットマップUI（ボタン・枠・帯）
2. ピクセル風UIウィジェット（ドット文字・ドット枠。ドット絵は背景素材の中だけの表現）
3. ピンク系有彩色のUI使用（識別線）
4. 色付き影・グロー・アウターグロー・虹色/多色グラデーション（グラデはヴェールの単色フェードのみ可）
5. テキストへの drop-shadow・縁取り（サーフェスに置けば不要）
6. UI要素の回転・スキュー配置（手作り感の演出禁止。傾けてよいのは fx層の金平糖だけ）
7. 点滅・マーキー・無限バウンス・カウントダウン
8. 絵文字のアイコン代用・装飾散らし
9. キャラ画像の隙間埋め配置（キャラは機能を持つ場所のみ: ロゴ・キャラバンド・商品写真・空状態。コマアニメは1ページ1個まで — グローバルルール）
10. 角丸・影・枠線の規格外カスタム値

### 7-3. モーション節度

- トークンは `--dur-quick: 160ms` / `--dur-base: 280ms` / `--ease-pop` を維持。
- スクロール出現: opacity 0→1 + translateY **12px以内**・280ms・**1回きり**（再スクロールで再発火しない）。バウンス出現禁止。
- `--ease-pop`（バウンス）はマイクロフィードバック専用: カート追加成功・バッジ更新・トースト。レイアウト移動には使わない。
- hover: 浮き2px+shadow-popまで。コンテンツのパララックス禁止（fx層の金平糸ジャイロは聖域維持）。
- カルーセル: 自動送りするなら6-8秒・一時停止ボタン常設・**ユーザー操作後は恒久停止**・`prefers-reduced-motion` で自動送り停止（motion.jsの聖域と整合）。

### 7-4. 金平糖（fx層）の色例外

hero-3d の金平糖はfx層専用として淡い砂糖色（低彩度パステルのミックス）を許可。ただし**UI層（content以上）に金平糖パレットを持ち込むこと禁止**。個数・密度・静止挙動の調整は聖域ルール内で可、大粒禁止。

## 8. 全年齢対応・アクセシビリティ原則

1. **コントラスト**: 本文・UI文字はすべて §3-2 の実測AA表のペアのみ。新ペアは実測してから。
2. **フォーカス**: すべての対話要素に `:focus-visible { outline: 2px solid var(--ink); outline-offset: 2px; }`。honey面上でも墨アウトラインで視認可。フォーカス消し（outline:none単独）禁止。
3. **タップ**: 44×44px最小（数量±・削除・カルーセル矢印・閉じる含む）。
4. **色以外の手掛かり**: 状態は必ず文字併記（§6-3）。リンクは下線。エラーは色+文言。
5. **モーション**: `prefers-reduced-motion` で出現アニメ・自動送り・金平糖挙動を停止（motion.js聖域）。点滅は3回/秒以上を一切含まない。
6. **正直な商売（全年齢の信頼）**: 偽の希少性・購買圧演出禁止。在庫・送料・発送日数・売り切れは事実のみ静かに表示（ec-ux-knowhow §2-3/4-3 準拠）。
7. **画像**: 商品画像に内容altを必須。装飾画像（世界の窓・金平糖canvas）は `alt=""` / `aria-hidden`。
8. **カルーセル**: 一時停止ボタン常設・現在位置表示（ドット）・矢印はキーボード操作可。
9. **文言のトーン**: こすくまくんの声は聖域として一切変更しない。デザインは声を邪魔しない器に徹する。
