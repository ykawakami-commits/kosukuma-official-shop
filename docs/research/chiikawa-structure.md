# ちいかわマーケット 構成分析（構造とUXの型）

調査日: 2026-07-27〜28 ／ 対象: https://chiikawamarket.jp/（トップ・コレクション・商品詳細）
手段: curl による HTML/テーマCSS取得 + Puppeteer 実測（PC 1366×768・1280×800・1920×1080、SP 402×874 iPhone 16 Pro基準）

> ## ⚠️ 複製除外の明記（最重要）
> 本文書が複製対象とするのは **「構造とUXの型」だけ** である。
> 以下は **一切複製しない**:
> - **デザイン・配色**（ピンク／ストライプ／星柄背景・アクセント色・ちいかわ実測色 #e77277 等。現行 tokens.css に残る実測色はデザインシステムで独自パレットに置換すること）
> - **画像・キャラクター・イラスト表現**（キャラ集合絵・フッターGIF・挨拶ピル内の口調等の固有表現）
> - **固有の装飾**（5周年ロゴ演出、キャラ配車バナー絵柄、雲形・ハート形などの固有シェイプ）
> - **文言のトーン**（「こんにちはッ！ゲストさん」等の固有コピー）
>
> 見た目はこすくまくん独自のトーン（クリーム体色・黒太アウトライン・はちみつ・金平糖・秘密基地の世界観）で新規に作る。

## 1. ページ全体の構成順序（トップページ）

Shopifyセクション実測スタック（PC 1366×768 / SP 402×874、top+height px）:

| # | セクション | PC top / h | SP top / h | 役割 |
|---|-----------|-----------|-----------|------|
| 1 | アナウンスバー | 0 / 39 | 0 / 63 | 回転式1行トピック（3件ローテーション、左右矢印） |
| 2 | ヘッダー | 39 / 142 | 63 / 70 | ロゴ＋ユーティリティ＋グローバルナビ（**sticky**） |
| 3 | 重要注意行 | 181 / 63 | 133 / 45 | 決済等のクリティカル告知テキストリンク1行 |
| 4 | ヒーローカルーセル | 244 / 511 | 178 / 380 | **カード型スライダー**（後述） |
| 5 | 新着商品 | 756 / 1707 | 558 / 2235 | 12商品グリッド＋「もっと見る」 |
| 6 | おすすめ商品 | 2463 / 1733 | 2792 / 2133 | 12商品グリッド＋「もっと見る」 |
| 7 | 最近チェックした商品 | 4195 / 308 | 4925 / 215 | パーソナライズ枠（未閲覧時は薄い） |
| 8 | お知らせ（ブログ） | 4503 / 725 | 5139 / 583 | 日付付き記事3件＋もっと見る |
| 9 | フッターバナー群 | 5228 / 886 | 5722 / 628 | 会員登録/ガイド/FAQ/お知らせの4バナー＋特設2枚 |
| 10 | フッターイラスト帯 | 6114 / 405 | 6350 / 163 | 全幅ブランド帯（世界観の締め） |
| 11 | フッター本体 | 6519 / 364 | 6512 / 793 | 法定リンク＋SNS＋© |

**構成の型**: 「告知 → ブランド＋導線 → 重要注意 → 販促カルーセル → 商品（新着→おすすめ→履歴）→ 情報（お知らせ）→ 信頼（ガイド/FAQ/法定）→ 世界観の締め」。
商品より上に置く非商品要素は「告知2種＋カルーセル」だけに絞られており、**トップ＝実質的な商品一覧**として機能する。総ページ高はPC 6,884px / SP 7,305px。

### 下層ページの構成順序
- **コレクション（一覧）**: アナウンス → ヘッダー → コレクションバナー（タイトル） → 並び替え＋絞り込み → 商品グリッド（64件/ページ＋ページネーション） → フッター3点セット。トップと共通シェルで挟む。
- **商品詳細**: アナウンス → ヘッダー → 重要注意行 → パンくず（ホーム > コレクション） → メイン（ギャラリー｜情報カラム。情報カラムは `product__column-sticky` で**スクロール追従**） → 最近チェックした商品 → 関連商品 → フッター3点セット。
- 商品情報カラムの要素順: 商品名 → ベンダー → **JANコード** → 価格（税込表記＋セール/売切バッジ） → 数量セレクト（購入上限注記付き） → お気に入り追加 → カート追加ボタン（売切時は「売り切れ」でdisabled） → 受取可否 → 説明。
- `<title>` は全ページ「ページ名 | ちいかわマーケット 公式グッズショップ」形式で**「公式」を必ず含む**。

## 2. ファーストビュー実測（viewport比）

### PC（フォールドまでに何を見せるか）

| viewport | 商品セクション上端 | フォールド比 | スライダー高 |
|----------|----------------|------------|------------|
| 1280×800 | 727px | 90.9% | 483px |
| 1366×768 | 756px | 98.4% | 511px |
| 1920×1080 | 940px | 87.0% | 696px |

内訳（1366×768）: アナウンス38px(4.9%) + ヘッダー142px(18.5%) + 注意行63px(8.2%) + カルーセル511px(66.5%)。

**重要な型**: PCでは商品グリッド自体はほぼフォールド外（98.4%）だが、初期ビューが痩せて見えない。理由はカルーセルが**装飾ヒーローではなく「商業情報カード」の同時複数表示**だから:
- スライドは 407×407px のカード型（1366時）で、**3枚全表示＋左右に次カードのチラ見せ（peek）**（可視5枚）
- 各カードの中身は「新商品ビジュアル」「プレゼントキャンペーン（条件・日付入り）」「夏季休業の告知（日付・注意書き入り）」＝1枚目から実務情報が満載
- つまり「ファーストビュー＝ブランド演出」ではなく「**ファーストビュー＝お店の店頭ポスター3枚**」という設計

### SP（402×874）

| 要素 | top / h | フォールド比累計 |
|------|---------|---------------|
| アナウンス（2行折返し） | 0 / 63 | 7.2% |
| ヘッダー | 63 / 70 | 15.2% |
| 注意行 | 133 / 45 | 20.4% |
| カルーセル | 178 / 380 | 63.8% |
| 新着商品セクション | 558〜 | タイトル＋**商品カード上段約200pxがフォールド内** |

**SPでは初期画面に商品カードが必ず入る**（商品開始63.8%地点）。カルーセルは306×306pxカード1枚＋左右peek。モバイルこそ「すぐ商品」の優先度が高い。

## 3. ヘッダー構造

### PC（2段構成、計142px、position: sticky）
- **上段（約97px）**: CSS Grid `200px 250px 366px 250px 200px` の**左右対称5カラム**。
  - 中央: ロゴ（300×83px）— 唯一の主役
  - 左上: ゲスト挨拶ピル（ログイン状態の可視化）
  - 右: 関連サブブランドへのバナー3連（映画/パーク/くじ ≒ 別事業導線）＋機能アイコン3個（お気に入り56×56 / ログイン56×56 / カート56×56、**ラベル文字付き**）
- **下段（45px）**: グローバルナビ7項目＋検索フィールド（右端）
  - `新着商品 ▾ / 再入荷商品 ▾ / キャラクターから探す ▾ / シリーズから探す ▾ / 商品カテゴリから探す ▾ / ご利用ガイド / よくあるご質問`
  - **ナビにガイドとFAQを常設**（フッターと二重配置）するのが公式ECの型

### SP（1段70px、sticky）
- CSS Grid `48px 276px 48px` = ハンバーガー(44×44) / ロゴ中央(220×61) / カート(44×44)
- 機能はカートだけ残し、他は全部ドロワーへ。**タップターゲット44px確保**
- ドロワー内はPCと同一のメニュー階層（アコーディオン展開）＋ガイド/お気に入り/ログイン/カート

## 4. カテゴリ導線（メガメニューの4軸分類）

ドロップダウン（PC）／ドロワー（SP）は同一データで、**4つの独立した探し方の軸**を提供する:

| 軸 | 中身 | 件数感 | 型のポイント |
|----|------|--------|------------|
| **時間軸** | 新着商品一覧 → 「8月7日発売」「7月24日予約」等の**発売日別コレクション** | 日付10件+ | 発売日・予約・再入荷を全部コレクション化。リピーターは「日付」で探す |
| **時間軸2** | 再入荷商品一覧 → 再入荷日別 | 3-4件 | 再入荷にも独立した軸を与える |
| **キャラクター軸** | キャラ別17件＋「キャラクター一覧」 | 17+ | ファンの第一想起はキャラ。末尾に必ず「一覧」へのまとめリンク |
| **シリーズ軸** | 企画・コラボ・イベント別22件＋「シリーズ一覧」 | 22+ | 「企画単位」の棚。期間限定企画を資産化して残す |
| **カテゴリ軸** | ぬいぐるみ/雑貨/アパレル/文房具…15件＋「予約商品」「全商品」「カテゴリ一覧」 | 15+ | 実用軸。**「全商品」を必ず末尾に置く**（逃げ道） |

- 各軸の末尾に「〜一覧」リンク → `/collections/` ハブページのアンカー（#character / #series / #category）へ着地。**メニューで迷ったらハブページで俯瞰**できる二重構造。
- 検索フィールドはPCはナビ右端に常設、SPはドロワー内。
- こすくま適用: SKUが少ない現状は軸を「新着 / キャラクター（こすくま・しゃーろっくま等）/ カテゴリ」の2-3軸に縮約してよいが、**「軸が複数ある」構造自体**が公式ECの型。1軸しかないナビはファンサイトに見える。

## 5. ヒーローカルーセルの型

| 項目 | PC(1366) | SP(402) |
|------|---------|---------|
| 全体高 | 511px（上pad 48px） | 380px（上pad 24px） |
| スライド | 407×407 カード型 | 306×306 カード型 |
| 同時表示 | 3枚フル＋左右peek | 1枚＋左右peek |
| 操作 | 左右矢印＋一時停止ボタン | スワイプ＋ページネーションドット＋一時停止 |
| 実スライド数 | 10枚前後（ループclone込みDOM 22） | 同 |

- スライドのリンク先は 商品直リンク / 特設ページ / コレクション / ブログ記事 と多様。**カルーセル＝「今売りたい・伝えたい」の統合枠**であり装飾ではない。
- **一時停止ボタンを必ず置く**（アクセシビリティ。alt も「スライダーを再生/停止」で実装）。
- 角丸カード＋peekにより「まだ横にある」ことが視覚で伝わり、自動送りに頼らない。
- こすくま適用: 現行の全幅1枚ヒーロー（装飾パネルのみ）は初期ビューの商業情報量が実質0になる実測済み欠点。**カード型・複数枚同時表示・1枚目から商品/キャンペーン情報**へ転換するのが本質的な改善。

## 6. 商品グリッドとカードの情報設計

### グリッド規則（実測）

| 項目 | PC(1366) | SP(402) |
|------|---------|---------|
| コンテナ | max-width 1400px・左右pad 50px（実効1266px） | 左右pad 15px（実効372px） |
| 列数 | **4列**（307.5px均等） | **2列**（180px均等） |
| gap | 12px × 12px | 12px × 32px（縦を広めに） |
| 1セクションの商品数 | 12個（4×3） | 12個（2×6） |
| カード | 308×418px・内pad 16px | 180×294px・内pad 8px |

- 1920×1080でもコンテナは1400pxで止め、左右余白260pxずつ（**中央寄せ固定幅**。全幅に伸ばさない）。
- セクション下端に「もっと見る」ボタン（220×54px、**中央配置・1個だけ**）→ 対応コレクションへ。グリッドで見せるのは12個で打ち切り、無限に並べない。

### 商品カードの情報量と優先順位（上から）

1. **バッジ（左上）**: 「販売開始前」「売り切れ」等のステータス。**状態は画像に重ねず角に**
2. **お気に入りボタン（右上）**: カードから1タップで保存
3. **商品画像**: カード幅いっぱいの**正方形1:1**（PC 274×274 / SP 162×162、カード高の65%）。hover で2枚目画像に切替
4. **商品名**: PC 16px/500・SP 13px/500、**2行想定**。「ちいかわ×スッパイマン マスコット（ちいかわ）」のように「シリーズ名＋品種＋（キャラ名）」の完全名を省略せず表示
5. **価格**: **右揃え**・「¥2,200 (税込)」形式。(税込)は小さめの別スパン。セール時は取り消し線＋セール価格の2段構造を持つ

カードに載せるのは**この5点だけ**。説明文・レビュー・ボタン類（カート追加）はカードに置かず詳細ページに送る。カード全体が1つのリンク。

### セクション見出しの型
- 「新着商品」→ 小さい日本語ラベル＋大きい英語ラベル（NEW ITEMS / RECOMMEND / INFORMATION）の**2言語2段見出し・中央揃え**
- 見出し領域はセクション上端から約71px（上pad）+ 見出し + 約100pxで grid 開始。リズムが全セクション同一

## 7. 余白とグリッドの規則性

- **基準単位はほぼ12px**（グリッドgap 12、カード内pad 16/8、セクション上pad 71≒72=12×6、フッターバナー上下pad 96=12×8）
- セクション間は**背景色の切替で区切る**（余白だけに頼らない）: アナウンス=濃 → ヘッダー=中 → ナビ=淡 → 本文=交互。境界線なしで「ゾーン」が分かる
- コンテンツ幅は全セクション統一（1400px上限・pad 50px）。フッターイラスト帯とカルーセルのみ全幅ブリード
- カード角丸・白背景でコンテンツ面を浮かせ、背景パターンと分離（※パターン柄自体は複製しない。「背景とカードのレイヤー分離」という構造だけ採用）

## 9. フッター構造（信頼ゾーンの3層）

1. **フッターバナー層**: 「会員登録 / ご利用ガイド / よくあるご質問 / お知らせ」の**4バナー横並び**（SPは2×2）＋特設コンテンツバナー＋外部サービス。初見の不安を潰す導線を絵で並べる
2. **ブランド帯層**: 全幅イラスト1枚（世界観の締め。機能なし）
3. **法定・SNS層**:
   - お問い合わせバナー（メールフォームへ）
   - 法定リンク9本: `利用規約 / プライバシーポリシー / 特定商取引法に基づく表記 / 企業情報(運営会社サイトへ) / 利用ガイド / よくあるご質問 / お問い合わせ / OEMのご相談 / カスタマーハラスメントに対する基本方針`
   - SNSアイコン5個（X / Instagram / TikTok / YouTube / LINE）— **フッターにのみ集約**、本文に散らさない
   - コピーライトは**権利者＋制作委員会＋運営会社のトリプル表記**（`©nagano ©nagano / chiikawa committee ©Gray Parka Service`）。こすくまは「© こすくまくん / 株式会社こす.くま」のダブル表記が対応形

## 10. お知らせ（Information）の型

- トップに日付付き記事**3件**＋もっと見る（ブログ一覧へ）
- 掲載内容は実測で「夏季休業」「決済メンテナンス」「決済システム障害（更新時刻付き）」— **ネガティブ・実務情報を隠さず日付/更新時刻付きで出すのが最大の信頼シグナル**
- さらに緊急度の高い1件は「重要注意行」としてヘッダー直下に常設昇格（2階層運用）

## 11. こすくま公式ECへの適用チェックリスト（構造のみ）

- [ ] トップの構成順序を「告知 → ヘッダー(sticky) → 重要注意(必要時) → カード型カルーセル → 商品グリッド → お知らせ → 信頼バナー → ブランド帯 → 法定フッター」に揃える
- [ ] カルーセルを全幅装飾1枚 → **正方形カード型・peek付き・1枚目から商品/キャンペーン情報**へ（PC3枚/SP1枚+peek、一時停止ボタン付き）
- [ ] SPでフォールド64%地点までに商品カード到達（現行実測は要改善）。PCは98%以内でも可、ただしカルーセル自体を商業情報化すること
- [ ] グリッド: PC4列/SP2列、gap 12px基準、コンテナ1400px上限、1セクション12個＋「もっと見る」1個
- [ ] カード情報は「バッジ/お気に入り/正方形画像/完全商品名2行/税込価格右揃え」の5点に限定
- [ ] ナビは複数軸（新着/キャラ/カテゴリ）＋ガイド/FAQ常設、末尾に「全商品」
- [ ] セクション見出しは日英2段・中央揃えで統一リズム
- [ ] フッター3層（バナー→ブランド帯→法定+SNS+©）と法定リンク（利用規約/プライバシー/特商法/運営会社/ガイド/FAQ/問い合わせ）
- [ ] 日付付きお知らせ枠（ネガティブ情報も掲載）＋重要時はヘッダー直下昇格
- [ ] `<title>` に「公式」を含める（例: こすくまくんのおみせ｜こすくまくん公式グッズショップ）
- [ ] stickyヘッダー＋上へ戻るFAB、SPタップターゲット44px
- [ ] **tokens.css のちいかわ実測色（#e77277等）を独自パレットへ全置換**（複製ルール順守）
